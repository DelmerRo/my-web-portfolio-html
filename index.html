Inventory Management System - Utama

Full Stack Developer | Proyecto Personal · Oct 2025 - Presente
Aplicado en Utama Home & Deco (ecommerce real en producción)
Spring Boot React PostgreSQL TypeScript Cloudinary TailwindCSS
En Producción Caso de uso real Full Stack CI/CD

Problema real: Vendo en dos canales, Tiendanube y MercadoLibre. El stock no se sincroniza entre plataformas, lo que genera un problema grave: puedo vender en un canal un producto que ya no tengo disponible porque se vendió en el otro. Esto produce sobreventas, mala experiencia al cliente y pérdida de credibilidad. Además, cuando recibo mercadería de un proveedor, el proceso de control es tedioso: al contar el físico pueden surgir diferencias (productos faltantes, sobrantes o cantidades incorrectas) y sin un registro claro es imposible hacer un reclamo efectivo.

Solución: Un sistema que centraliza y ordena todo el proceso comercial. El stock se gestiona desde un solo lugar, eliminando el desorden de vender por canales separados. Minimiza considerablemente el riesgo de sobreventa al tener un único registro de stock confiable. Permite cargar la mercadería física recibida y genera reportes claros de diferencias por SKU o por producto completo faltante/sobrante, para gestionar reclamos con los proveedores de forma ágil.

Mi contribución técnica: Desarrollo full stack completo del sistema, aplicando 14 años de experiencia en procesos comerciales.

  • Dashboard con KPIs en tiempo real: Filtros dinámicos que actualizan automáticamente total de productos, activos, inactivos, stock bajo y sin stock.
  • Búsqueda inteligente: Buscar productos tanto por SKU propio como por SKU del proveedor, mostrando siempre todas las métricas útiles del producto.
  • Historial completo por producto: Cada producto tiene su propio registro con todos los movimientos de entrada y salida, permitiendo trazabilidad total.
  • Múltiples SKU por proveedor: Cada producto puede asociarse a 1 o más proveedores, y cada proveedor le asigna su propio código.
  • Gestión de proveedores, categorías y subcategorías: Estructura jerárquica completa para organizar el catálogo.
  • Imágenes persistentes en Cloudinary: Cada producto tiene una foto para identificarlo visualmente.
  • Registro de dimensiones: Cargar medidas del producto para calcular volumen y saber cuánto cobrar por envío.
  • Tipos de movimiento detallados: Motivos de entrada/salida para análisis de causas.
  • Backend (Spring Boot): APIs REST con Java 17, Spring Security (JWT), JPA/Hibernate y PostgreSQL.
  • Frontend (React + TypeScript): Dashboard con Zustand, TailwindCSS y React Router.
  • Deploy: Backend en Render con CI/CD, frontend en Vercel.
Aptitudes demostradas: Spring Boot React TypeScript PostgreSQL JWT Security Cloudinary Zustand TailwindCSS REST API CI/CD
Propósito del proyecto:
Proyecto personal desarrollado para profundizar habilidades técnicas en un entorno real, con código limpio, buenas prácticas y despliegue en producción.
